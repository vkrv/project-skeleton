# Feature docs

Each feature gets a markdown file in this folder. Register it in [../INDEX.md](../INDEX.md) and tick ROADMAP checkboxes as status changes.

## Template

```markdown
# Feature name

**Status:** planned | in-progress | shipped

## Summary

One short paragraph.

## Related

- Schema: …
- API: …
- Client: …
- Linked features: …

## Behavior

…

## Open questions

- …
```

See also `.cursor/rules/020-docs-and-crossrefs.mdc`.
